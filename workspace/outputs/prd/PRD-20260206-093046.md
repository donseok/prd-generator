## 1. 개요

### 1.1 배경

현재 ○○제철 냉연공장의 MES(ColdMES v3.2, 2012년 구축)와 APS(PlanOptima v2.0, 2015년 구축)는 별도 시스템으로 운영되고 있다. 두 시스템 간 데이터는 EAI 미들웨어를 통해 15분 배치 주기로 연동되며, 피크 시 최대 30분까지 지연이 발생한다. 이로 인해 설비 고장·긴급 수주 시 실시간 의사결정이 불가능하고, 계획 대비 실적 일치율이 68%에 그치고 있다.

MES 서버(HP-UX, Oracle 11g)의 노후화로 화면 응답 시간이 평균 5.2초(피크 12초)에 달하며, 현장 실적 입력 지연으로 월평균 340건의 수작업 보정이 발생한다. APS는 냉연 공정 특수 제약조건(두께 점프, 강종 전환, 코일 이송 시간, 에너지 최적화 등)을 반영하지 못해 스케줄 준수율이 72%에 불과하고, 생산관리팀은 주 2~3회 수작업 재계획에 회당 4시간을 소비한다.

글로벌 Top Tier 철강사의 OEE가 88%인 데 비해 당사는 78%로 10%p 격차가 있으며, 기존 시스템 유지보수에 연간 8억원이 소요되고 있다. PI(Process Innovation) 관점에서 MES와 APS를 단일 통합 플랫폼으로 재구축하여 스마트팩토리 수준의 생산 운영 체계를 확립할 필요가 있다.

### 1.2 목표
- MES와 APS를 하나의 통합 플랫폼으로 구축하여 실시간 양방향 데이터 흐름 실현 (연동 지연 15분 → 2초 이내)
- 냉연 공정 특화 15개 제약조건을 반영한 APS 스케줄링 최적화 (스케줄 준수율 72% → 90%)
- 코일 단위 전 공정 실시간 추적 체계 구축 (코일 위치 정확도 85% → 99%)
- 통합 품질 관리 및 SPC 실시간 모니터링으로 품질 이상 즉시 대응
- 데이터 기반 KPI 관리 및 의사결정 지원 체계 구축
- PI 기반 업무 프로세스 혁신으로 수작업 최소화

### 1.3 범위

#### 포함 범위
- 냉연 전 공정 9개 라인: PCM, BAF, CAL, EGL, CGL, SPM, RCL, SL, CCL
- APS 핵심: 통합 생산계획, 제약조건 기반 스케줄링(15개 제약), 실시간 조정, 수주-생산 연계
- MES 핵심: 작업지시, 코일 추적(RFID+바코드), 실시간 데이터 수집(OPC-UA), 품질 관리, 설비 관리, WIP 관리
- 통합 기능: 대시보드, KPI 관리, 데이터 분석/리포트, 시스템 연동(ERP, L2, LIMS, WMS, EMS)
- 인프라: 마이크로서비스 아키텍처, 이벤트 기반 처리(Kafka), 하이브리드 클라우드
- 변화관리: 사용자 교육 프로그램, 현장 슈퍼유저 양성, 병행 운영
- 전자 품질 성적서 자동 생성, 클레임 역추적(30분 이내), 표면검사 이미지 연동

#### 범위 외
- AI/ML 기반 품질 예측 모델 (2차 범위로 확정)
- 모바일 앱 승인 프로세스 및 설비 점검 체크리스트 (2차 범위)
- 열연/후판 공장 확대 적용 (아키텍처만 고려, 실제 구현은 후속 프로젝트)
- 원가 분석 연동 (P3, 선택)

## 2. 기능 요구사항 (Functional Requirements)

### FR-001: 통합 생산계획 수립
**우선순위**: HIGH
**설명**: 월간/주간/일간 생산계획을 단일 화면에서 수립한다. ERP(SAP S/4HANA) 수주 데이터를 실시간 연동(RFC/BAPI)하여 자동 계획 초안을 생성하고, 코일 단위 세부 스케줄링과 납기일 역산 방식의 자동 일정 산출을 지원한다.

**User Story**: 생산관리자로서, 나는 수주 정보를 기반으로 월/주/일 생산계획을 단일 화면에서 수립하고 싶다, 4시간 걸리는 계획 수립 시간을 30분 이내로 단축하기 위해.

**Acceptance Criteria**:
- [ ] 월간/주간/일간 계획을 동일 화면에서 수립·조회·수정할 수 있다
- [ ] ERP 수주 데이터를 실시간(3초 이내)으로 조회하여 자동 계획 초안을 생성한다
- [ ] 코일 단위(코일 ID) 세부 스케줄링이 가능하다
- [ ] 납기일 역산 방식으로 각 공정 착수일을 자동 산출한다
- [ ] 계획 수립 소요 시간이 30분 이내이다 (1주일 계획 기준)

### FR-002: 제약조건 기반 스케줄링
**우선순위**: HIGH
**설명**: 냉연 공정 특화 15개 제약조건을 APS 엔진에 반영한 최적 스케줄링을 수행한다. 상용 APS 엔진 기반에 냉연 특화 제약조건 모듈을 커스텀 개발하며, 휴리스틱 + 메타휴리스틱(GA, SA) 하이브리드 접근을 적용한다.

**User Story**: 생산관리자로서, 나는 두께 점프·강종 전환·롤 교체·에너지 피크 등 냉연 특수 제약조건이 자동 반영된 스케줄을 받고 싶다, 수작업 재계획(주 2~3회)을 제거하기 위해.

**Acceptance Criteria**:
- [ ] PCM 두께 점프 제한(일반강 0.3mm, 고강도강 0.2mm)이 반영된다
- [ ] PCM 폭 변경 규칙(넓→좁 순서, 최대 200mm 점프)이 반영된다
- [ ] PCM 강종 전환 순서(저탄소→고탄소, 역방향 시 롤 세정 30분 추가)가 반영된다
- [ ] 워크롤 교체 주기(일반강 80km, 고강도강 60km, 스테인리스 40km)가 반영된다
- [ ] BAF 코일 적재 최적화(4단, 강종/규격 유사 조합, 무게 균형)가 반영된다
- [ ] CAL 강종 전환 시 소둔 온도 안정화 시간(50℃이내 15분, 50~100℃ 30분, 100℃초과 45분)이 반영된다
- [ ] EGL/CGL 도금량 변경 최소화(전환 시간 20분, 도금욕 460±5℃)가 반영된다
- [ ] 공정 간 코일 이송 시간(PCM→BAF 2hr, PCM→CAL 1hr 등)이 반영된다
- [ ] 전력 피크 시간대(14:00~17:00) 고에너지 강종 회피 스케줄링이 가능하다
- [ ] 코일 체류 시간 제한(PCM 출측 48hr, CAL 출측 24hr)이 반영된다
- [ ] 1주일 계획 기준 스케줄링 연산 시간이 5분 이내이다

**출처**: APS_제약조건_상세정의.csv:CR-001~CR-015, 냉연_통합MES_APS_요구사항.md:40-46, 현장_인터뷰_메모.txt:22-32, 2차_요구사항_검토_회의록.txt:14-34, PI_킥오프_회의록.md:67-72

### FR-003: 실시간 스케줄 조정
**우선순위**: HIGH
**설명**: Gantt Chart 기반 드래그&드롭 일정 변경, What-if 시뮬레이션(설비 고장·긴급 수주 영향도 분석), 자동 재스케줄링(실적 대비 계획 차이 발생 시 자동 보정), 계획 확정/미확정 구분 관리를 지원한다.

**User Story**: 생산관리자로서, 나는 설비 고장이나 긴급 수주 발생 시 시뮬레이션으로 영향도를 확인하고 즉시 일정을 조정하고 싶다, 실시간 변동 대응력을 확보하기 위해.

**Acceptance Criteria**:
- [ ] Gantt Chart에서 드래그&드롭으로 작업 순서를 변경할 수 있다
- [ ] What-if 시뮬레이션으로 설비 고장/긴급 수주 시나리오의 납기 영향도를 분석할 수 있다
- [ ] 실적 대비 계획 차이가 임계치를 초과하면 자동 재스케줄링이 트리거된다
- [ ] 계획 확정/미확정 상태를 구분 관리하며, 확정 계획은 변경 시 승인 프로세스를 거친다
- [ ] 계획 변경 이력(변경자, 변경 사유, 변경 전/후 비교)이 기록된다

**출처**: 냉연_통합MES_APS_요구사항.md:48-52, 현장_인터뷰_메모.txt:99-102

### FR-004: 수주-생산 연계
**우선순위**: HIGH
**설명**: SAP S/4HANA ERP와 실시간 양방향 연동(RFC/BAPI)하여 수주 데이터를 기반으로 우선순위 자동 반영(납기, 고객 등급, 수익성), 가용 재고(모코일) 자동 할당, 잔여 능력 실시간 조회를 수행한다.

**User Story**: 생산관리자로서, 나는 ERP 수주가 등록되면 자동으로 생산계획에 반영되고 납기 위험 코일을 알림 받고 싶다, 납기 준수율을 92%에서 97%로 향상시키기 위해.

**Acceptance Criteria**:
- [ ] ERP 수주 데이터가 실시간(3초 이내)으로 MES/APS에 반영된다
- [ ] 납기·고객 등급·수익성 기반 수주 우선순위가 자동 산정된다
- [ ] 가용 모코일 재고가 수주에 자동 할당된다
- [ ] 라인별 잔여 능력(Available Capacity)을 실시간 조회할 수 있다
- [ ] 납기 위험 코일(납기 D-3일 이내 미착수)에 대한 자동 알림이 발생한다
- [ ] 수주별 진행 상황(대기→생산중→완료→출하)을 실시간 추적할 수 있다

### FR-005: 작업지시 관리
**우선순위**: HIGH
**설명**: APS 확정 계획 기반으로 작업지시를 자동 생성하고, 라인별 작업지시 큐 관리, 상태 관리(대기→준비→진행→완료→마감), 긴급 작업지시 삽입 및 우선순위 변경을 지원한다.

**User Story**: 현장 조업자로서, 나는 APS에서 확정된 작업지시가 자동으로 내 라인 큐에 표시되고 순서대로 실행하고 싶다, 엑셀 메일을 확인하고 수동 입력하는 과정을 없애기 위해.

**Acceptance Criteria**:
- [ ] APS 계획 확정 시 해당 라인 작업지시가 자동 생성된다
- [ ] 라인별 작업지시 큐에서 대기/진행/완료 상태를 실시간 확인할 수 있다
- [ ] 긴급 작업지시를 기존 큐 중간에 삽입할 수 있다
- [ ] 이전 코일의 작업 조건을 복사하여 신규 작업지시에 적용할 수 있다
- [ ] 작업지시 상태 전환 시 타임스탬프와 담당자가 자동 기록된다

### FR-006: 코일 추적 관리 (Coil Tracking)
**우선순위**: HIGH
**설명**: 코일 ID 기반 전 공정 이력 추적, 실시간 위치 추적(라인 내/야드/창고), 코일 분할(Slitting)/합병 이력, 모코일-자코일 계보(Genealogy) 관리를 수행한다. PCM/CAL 라인은 RFID, 나머지 라인은 바코드/QR 스캔 방식을 적용한다.

**User Story**: 현장 조업자로서, 나는 코일의 현재 위치와 전 공정 이력을 실시간으로 확인하고 싶다, 야드맨에게 무전으로 물어봐야 하는 상황(평균 25분)을 없애기 위해.

**Acceptance Criteria**:
- [ ] 코일 ID로 전 공정 이력(공정별 작업 조건, 품질 결과, 타임스탬프)을 조회할 수 있다

### FR-018: 비상 운영 모드
**우선순위**: HIGH
**설명**: 네트워크 장애 시 각 라인이 독립적으로 최소 4시간 운영할 수 있도록 로컬 캐시 기반 비상 운영 모드를 지원한다. 네트워크 복구 후 데이터를 자동 동기화한다.

**User Story**: 현장 조업자로서, 나는 네트워크 장애가 발생해도 작업지시 확인과 실적 입력을 계속할 수 있어야 한다, 생산 중단 없는 연속 운영을 위해.

**Acceptance Criteria**:
- [ ] 네트워크 장애 감지 시 자동으로 비상 운영 모드로 전환된다
- [ ] 로컬 캐시에 저장된 작업지시/마스터 데이터로 최소 4시간 독립 운영이 가능하다
- [ ] 비상 모드에서 입력된 실적 데이터가 로컬에 저장된다
- [ ] 네트워크 복구 시 자동 데이터 동기화가 수행된다

**출처**: 2차_요구사항_검토_회의록.txt:114-117
