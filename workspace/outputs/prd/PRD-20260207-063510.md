## 1. 개요

### 1.1 배경

현재 냉연공장의 MES(Manufacturing Execution System, 2012년 구축)와 APS(Advanced Planning & Scheduling, 2015년 구축)가 별도 시스템으로 운영되고 있습니다. 두 시스템 간 데이터 연동이 15분 배치 방식으로 이루어져 실시간 의사결정이 불가능하며, 계획 대비 실적 일치율이 68%에 불과합니다.

레거시 MES 시스템의 노후화로 화면 응답시간이 평균 5.2초(피크 시 12초)에 달하고, 연간 유지보수 비용이 8억원으로 증가하고 있습니다. 또한 APS가 냉연 공정의 특수 제약조건(두께 점프, 강종 전환, 롤 교체 주기, 코일 이송 시간 등)을 반영하지 못해 수작업 재계획이 주 2~3회 발생하고 있습니다.

글로벌 Top Tier 철강사의 OEE가 88%인 반면, 현재 78%로 10%p의 격차가 존재합니다. 이러한 문제들을 해결하고 스마트팩토리 수준으로 도약하기 위해 MES와 APS를 하나의 통합 플랫폼으로 구축하는 PI(Process Innovation) 프로젝트가 필요합니다.

### 1.2 목표

- **생산성 향상**: OEE 5%p 개선 (78% → 83%)
- **납기 준수율**: 92% → 97% 달성
- **품질 개선**: 불량률 1.2% → 0.7% 감소
- **운영 효율**: 계획 수립 시간 87% 단축 (4시간 → 30분)
- **재고 최적화**: 재공 재고 15% 절감
- **에너지 절감**: 에너지 비용 8% 절감
- **실시간 통합**: MES-APS 간 실시간 데이터 연동 (15분 → 2초 이내)

### 1.3 범위

#### 포함 범위
- 냉연 전 공정 9개 라인 (PCM, BAF, CAL, EGL, CGL, SPM, RCL, SL, CCL)
- 통합 MES/APS 플랫폼 신규 구축
- ERP(SAP S/4HANA), Level 2, LIMS, WMS, EMS 연동
- 실시간 데이터 수집 (OPC-UA 기반)
- 통합 대시보드 및 KPI 관리
- 코일 추적 관리 (바코드 + RFID 병행)
- 품질 관리 고도화 (SPC, 자동 판정, 클레임 역추적)
- 변화관리 및 사용자 교육

#### 범위 외
- 품질 예측 AI/ML 모델 (2차 범위)
- 열연/후판 공장 확대 (향후 확장)
- 네이티브 모바일 앱 (PWA 방식으로 대체)
- 현장 화면 외 다국어 (관리자 화면만 영어/일본어)

### 1.4 대상 사용자

| 사용자 유형 | 인원 | 역할 및 주요 활동 |
|------------|------|------------------|
| 현장 조업자 | 약 200명 | 작업지시 확인, 실적 입력, 품질 검사, 코일 이송 |
| 생산관리자 | 약 30명 | 생산계획 수립, 스케줄 조정, 수주-생산 연계 |
| 품질관리자 | 약 15명 | SPC 관리, 품질 판정, 클레임 분석 |
| 설비관리자 | 약 10명 | 설비 상태 모니터링, 정비 계획, 롤 관리 |
| 경영진/팀장 | 약 15명 | KPI 모니터링, 의사결정, 리포트 조회 |
| IT 운영자 | 약 5명 | 시스템 운영, 모니터링, 마스터 관리 |

### 1.5 성공 지표

| KPI | AS-IS | TO-BE | 측정 방법 |
|-----|-------|-------|----------|
| OEE | 78% | 83% | 시스템 자동 산출 (가동률×성능×품질) |
| 납기 준수율 | 92% | 97% | 계획 대비 실적 출하일 비교 |
| 품질 불량률 | 1.2% | 0.7% | 불량 코일 톤수 / 총 생산량 |
| 스케줄 준수율 | 72% | 90% | 계획 대비 실적 일치 코일 비율 |
| 계획 수립 시간 | 4시간 | 30분 | 주간 계획 수립 소요 시간 |
| 코일 위치 정확도 | 85% | 99% | 시스템 위치 vs 실제 위치 일치율 |
| 클레임 분석 시간 | 16시간 | 2시간 | 클레임 접수~원인 보고 소요 시간 |
| 화면 응답 시간 | 5.2초 | 3초 이내 | 95th percentile 응답 시간 |

#### FR-001: 통합 생산계획 수립
**우선순위**: HIGH (P1)
**설명**: 월간/주간/일간 생산계획을 단일 화면에서 수립하고, 수주 정보를 기반으로 자동 계획 초안을 생성합니다. 코일 단위 세부 스케줄링과 납기일 역산 방식의 자동 일정 산출을 지원합니다.

**User Story**: 생산관리자로서, 나는 단일 화면에서 월간/주간/일간 계획을 수립하고 싶다, 계획 수립 시간을 단축하고 일관성을 유지하기 위해.

**Acceptance Criteria**:
- [ ] 월간/주간/일간 계획을 하나의 화면에서 조회 및 편집 가능
- [ ] ERP 수주 데이터 연동으로 계획 초안 자동 생성
- [ ] 코일 단위 세부 스케줄링 지원
- [ ] 납기일 역산 방식으로 공정별 시작/종료 일시 자동 계산
- [ ] 계획 확정/미확정 상태 구분 관리

#### FR-002: 제약조건 기반 스케줄링
**우선순위**: HIGH (P1)
**설명**: 냉연 공정 특화 제약조건을 반영한 최적 스케줄링을 수행합니다. 설비 능력, 두께 점프, 롤 교체 주기, 소둔로 장입 패턴, 도금량 변경, 에너지 비용 등 15개 이상의 제약조건을 반영합니다.

**User Story**: 생산관리자로서, 나는 냉연 공정 제약조건이 자동 반영된 스케줄을 받고 싶다, 수작업 재계획을 줄이고 스케줄 준수율을 높이기 위해.

**Acceptance Criteria**:
- [ ] 두께 점프 제한 반영 (일반강 0.3mm, 고강도강 0.2mm 이내)
- [ ] 강종 전환 순서 규칙 반영 (저탄소→중탄소→고탄소)
- [ ] 롤 교체 주기 반영 (강종별 차등: 일반강 80km, 고강도강 60km)
- [ ] 공정 간 코일 이송 시간 반영 (PCM→BAF 2시간, PCM→CAL 1시간 등)
- [ ] 에너지 피크 시간대(14:00~17:00) 회피 스케줄링
- [ ] BAF 소둔로 코일 적재 패턴 최적화
- [ ] 도금량 변경 횟수 최소화

**출처**: APS_제약조건_상세정의.csv, 2차_요구사항_검토_회의록.txt (안건 1)

## 7. 부록

### 7.1 용어 정의

| 용어 | 정의 |
|------|------|
| MES | Manufacturing Execution System. 생산실행시스템으로 작업지시, 실적, 품질 관리 |
| APS | Advanced Planning & Scheduling. 고급 생산계획 및 스케줄링 시스템 |
| OEE | Overall Equipment Effectiveness. 설비종합효율 (가동률×성능×품질) |
| PCM | Pickling & Cold Rolling Mill. 산세-냉간압연 연속라인 |
| BAF | Batch Annealing Furnace. 상자소둔로 |
| CAL | Continuous Annealing Line. 연속소둔라인 |
| EGL | Electro Galvanizing Line. 전기아연도금라인 |
| CGL | Continuous Galvanizing Line. 용융아연도금라인 |
| SPM | Skin Pass Mill. 조질압연기 |
| RCL | Recoiling Line. 정정라인 |
| SL | Slitting Line. 슬리팅라인 |
| CCL | Color Coating Line. 컬러도장라인 |
| Level 2 | 공정 자동화 시스템 (PLC/HMI) |
| OPC-UA | Open Platform Communications Unified Architecture. 산업 자동화 통신 표준 |
| SPC | Statistical Process Control. 통계적 공정 관리 |
| LIMS | Laboratory Information Management System. 실험실 정보 관리 시스템 |
| WMS | Warehouse Management System. 창고 관리 시스템 |
| EMS | Energy Management System. 에너지 관리 시스템 |
| RFID | Radio-Frequency Identification. 무선 인식 기술 |
| RBAC | Role-Based Access Control. 역할 기반 접근 제어 |
| DMZ | Demilitarized Zone. 비무장지대 (네트워크 보안 영역) |
