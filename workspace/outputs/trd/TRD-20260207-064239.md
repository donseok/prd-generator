## 1. 기술 요약 (Executive Summary)

냉연 통합 MES/APS 시스템(NEXUS)은 기존 레거시 MES(2012년)와 APS(2015년)를 현대적인 마이크로서비스 아키텍처 기반의 통합 플랫폼으로 재구축하는 프로젝트입니다. 핵심 기술 목표는 MES-APS 간 실시간 데이터 연동(15분→2초), 화면 응답시간 개선(5.2초→3초), 그리고 99.9% 시스템 가용성 달성입니다.

본 시스템은 **클라우드 하이브리드 아키텍처**를 채택하여, 실시간 데이터 수집 및 핵심 트랜잭션은 On-premise에서 처리하고, 분석/리포팅은 클라우드에서 처리합니다. OT(Operational Technology) 네트워크와 IT 네트워크를 DMZ로 분리하여 산업 보안 요구사항을 충족합니다.

기술 스택은 Backend에 Java(Spring Boot)와 Python(APS 알고리즘), Frontend에 React+TypeScript, Database에 PostgreSQL+TimescaleDB(시계열), 메시지 브로커로 Apache Kafka를 선정하여 이벤트 기반 아키텍처(EDA)를 구현합니다. Level 2(PLC)와의 통신은 OPC-UA 프로토콜로 1초 주기의 실시간 데이터 수집을 지원합니다.

### 3.4 데이터 흐름

**실시간 데이터 수집 흐름**:
```
PLC/HMI → OPC-UA Server → Edge Gateway → Kafka → MES Service → TimescaleDB
                              ↓
                        (로컬 버퍼)
                      (네트워크 장애 시 4시간 보관)
```

**생산계획 흐름**:
```
SAP (수주) → Kafka → APS Service → 스케줄링 → MES Service → 작업지시
                ↓
        (우선순위 계산)
```

**품질 판정 흐름**:
```
Level 2 (실적) → MES Service → Quality Service → 자동 판정 → Hold/Pass
                                    ↓
                              (SPC 관리도)
                                    ↓
                              (관리 한계선 이탈 시 알람)
```
