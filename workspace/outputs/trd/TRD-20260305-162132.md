## 1. 기술 요약 (Executive Summary)

본 프로젝트는 로컬 서버의 CPU, 메모리, 디스크, 네트워크 리소스를 실시간으로 시각화하는 경량 웹 대시보드를 구축한다. 프론트엔드는 PRD에서 지정한 React + Recharts 기반으로 구현하며, 백엔드는 Python + FastAPI + psutil 조합으로 REST API를 제공한다.

아키텍처는 프론트엔드-백엔드 2계층 모놀리식 구조를 채택한다. 실시간성 요구(3초 간격 갱신)를 고려하여 프론트엔드에서 폴링(polling) 방식으로 API를 호출하고, 백엔드는 psutil을 통해 시스템 메트릭을 수집하여 JSON으로 응답한다. 데이터 영속화는 범위 외이므로 별도 데이터베이스 없이 인메모리 방식으로 운영한다.

다크 테마 UI는 CSS 변수 기반으로 구현하며, 반응형 그리드 레이아웃은 CSS Grid를 활용한다. 전체 시스템은 단일 서버에서 로컬 실행되며, Docker를 통한 컨테이너화로 배포 편의성을 확보한다.

### 3.2 계층별 설명
| 계층 | 설명 | 핵심 컴포넌트 |
|------|------|-------------|
| Presentation | React 기반 대시보드 UI, 차트 렌더링, 다크 테마 | CpuChart, MemoryChart, DiskChart, NetworkChart, DashboardLayout |
| API Gateway | FastAPI REST 엔드포인트, CORS 처리, 응답 직렬화 | SystemRouter, CORSMiddleware |
| Service | 시스템 메트릭 수집 비즈니스 로직 | MetricsCollector, CpuService, MemoryService, DiskService, NetworkService |
| Infrastructure | OS 레벨 시스템 정보 접근 | psutil 라이브러리 |

### 3.3 데이터 흐름

```
1. 브라우저 → [3초 Timer] → GET /api/v1/system/all
2. FastAPI Router → MetricsCollector.collect_all()
3. MetricsCollector → psutil.cpu_percent(), psutil.virtual_memory(),
                      psutil.disk_usage(), psutil.net_io_counters()
4. MetricsCollector → JSON 직렬화 → HTTP Response
5. React App → 응답 데이터 파싱 → 차트 State 업데이트 → Recharts 렌더링
```

## 4. 데이터베이스 설계 (Database Design)

### 4.1 데이터베이스 유형 및 엔진
- **유형**: 데이터베이스 없음 (인메모리)
- **사유**: PRD 범위에 히스토리 데이터 저장이 포함되지 않음. 실시간 스냅샷만 제공하므로 DB 불필요.

### 4.2 인메모리 데이터 구조

프론트엔드에서 차트 히스토리를 위해 클라이언트 측 상태로 관리:

```typescript
interface MetricDataPoint {
  timestamp: number;    // Unix timestamp (ms)
  value: number;        // 메트릭 값
}

interface ChartState {
  cpu: MetricDataPoint[];       // 최대 60개 (3분)
  memory: MetricDataPoint[];    // 최대 60개
  network_in: MetricDataPoint[];  // 최대 60개
  network_out: MetricDataPoint[]; // 최대 60개
}
```

### 4.3 데이터 보관 정책
- **클라이언트 측**: 최대 60개 데이터 포인트 유지 (3초 × 60 = 3분)
- **서버 측**: 상태 없음 (Stateless). 매 요청마다 현재 스냅샷만 반환
- **메모리 관리**: FIFO 방식으로 오래된 데이터 포인트 자동 제거

```
backend/

│   ├── __init__.py

│   ├── __init__.py
│   └── system_metrics.py      # Pydantic 응답 모델
└── core/
    ├── __init__.py
    └── config.py              # 설정 관리
```

### 10.2 MetricsCollector 서비스

```python
class MetricsCollector:
    """psutil 기반 시스템 메트릭 수집 서비스"""

    def get_cpu() -> CpuMetrics
    def get_memory() -> MemoryMetrics
    def get_disk() -> DiskMetrics
    def get_network() -> NetworkMetrics
    def get_all() -> SystemMetrics
```

네트워크 초당 전송량(bytes_per_sec) 계산을 위해 이전 측정값을 캐싱하며, `get_network()` 호출 시 delta를 계산한다.
