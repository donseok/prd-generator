## 1. 경영진 요약

경영진 요약문

현재 투자자들은 주식, 귀금속, 암호화폐 등 자산 정보를 파악하기 위해 다수의 사이트와 앱을 개별적으로 확인해야 하며, 이로 인해 정보 탐색에 과도한 시간이 소요되고 시장 변화에 대한 대응이 지연되고 있습니다. 정보의 분산은 투자 판단의 정확도를 떨어뜨리고, 기회 손실로 이어지는 핵심 문제입니다.

본 프로젝트는 국내외 주식, 금/은, 암호화폐 시세와 시장지수, 관련 뉴스를 하나의 웹 대시보드에서 실시간으로 통합 제공하는 플랫폼을 구축합니다. 투자자는 별도의 사이트 전환 없이 단일 화면에서 모든 자산군의 시세 변동과 차트, 최신 뉴스를 동시에 확인할 수 있습니다.

도입 시 투자 정보 탐색 시간을 약 60% 단축하고, 데이터 기반 의사결정 정확도를 약 30% 향상시킬 수 있습니다. 포트폴리오 모니터링 효율은 약 50% 개선되며, 뉴스 연동을 통한 시장 대응 속도 역시 약 40% 빨라질 것으로 기대됩니다. 이를 통해 사용자 만족도와 서비스 충성도를 높이고, 경쟁력 있는 투자 정보 플랫폼으로서의 시장 입지를 확보할 수 있습니다.

## 2. 프로젝트 개요

### 2.1 배경

투자자들이 다양한 자산군(주식, 귀금속, 암호화폐)의 시세와 시장 정보를 한눈에 파악할 수 있는 통합 웹 포털 대시보드의 필요성이 증가하고 있다. 분산된 금융 정보를 단일 플랫폼에서 실시간으로 제공하여 투자 의사결정을 지원하는 서비스를 구축한다.

### 2.2 목표

- 국내외 주식 시세 및 차트를 실시간으로 표시하는 웹 대시보드 구축
- 금/은, 암호화폐 등 다양한 자산군의 시세 통합 제공
- 국내외 시장지수를 한눈에 파악할 수 있는 대시보드 뷰 제공
- 관련 뉴스를 실시간으로 수집·표시하여 투자 판단 지원
- 실시간 데이터 업데이트를 통한 지연 없는 시세 반영

### 2.3 성공 기준

- 시세 데이터 실시간 갱신 지연시간 5초 이내
- 대시보드 초기 로딩 시간 3초 이내
- 일일 활성 사용자(DAU) 출시 3개월 내 1,000명 달성
- 사용자 평균 세션 체류시간 5분 이상
- 시스템 가용성(Uptime) 99.5% 이상 유지
- 표시 자산군 커버리지: 국내주식, 해외지수, 금/은, 암호화폐 전 항목 정상 제공

## 4. 솔루션 접근법

### 4.1 솔루션 개요

주식, 암호화폐, 금/은 등 다양한 금융 자산의 시세와 차트를 실시간으로 모니터링할 수 있는 웹 기반 대시보드 포털을 구축합니다. 사용자는 단일 화면에서 국내외 시장지수, 개별 종목 정보, 뉴스를 통합적으로 조회할 수 있으며, 위젯 기반의 유연한 종목 교체 구조를 통해 개인화된 모니터링 환경을 제공합니다. 업비트 API를 포함한 무료 공개 API들을 활용하여 비용 없이 실시간 데이터를 수집·표시하는 조회 전용 시스템입니다.

### 4.2 시스템 아키텍처

프론트엔드는 Next.js 14 + TypeScript 기반 SPA로 구성하며, Tailwind CSS로 깔끔한 반응형 대시보드 레이아웃을 설계합니다. 각 위젯(주식 차트, 뉴스, 종목 정보, 시장지수, 금/은 시세, 환율, 암호화폐 시세)은 독립적인 컴포넌트로 분리하여 종목 교체 및 재배치가 가능하도록 합니다. 차트 렌더링에는 TradingView Lightweight Charts(무료 오픈소스)를 사용하며, TanStack Query로 데이터 페칭 및 캐싱을 관리합니다. 백엔드는 Python 3.12 + FastAPI 기반 비동기 API 서버로 구성하여 외부 API(업비트 WebSocket API, 키움증권 Open API, metals.live, 한국수출입은행 환율 API, NewsAPI)로부터 데이터를 수집·정규화합니다. WebSocket을 통해 프론트엔드에 실시간 시세 데이터를 푸시하고, Redis를 캐싱 및 Pub/Sub 메시지 브로커로 활용합니다. 정적 데이터(종목 마스터, 뉴스, 사용자 설정)는 PostgreSQL 16에 저장합니다. 전체 인프라는 Docker Compose 기반으로 컨테이너화하며, 무료 티어 클라우드(Oracle Cloud Free Tier) 또는 자체 서버에 배포합니다.

### 4.3 기술 스택

### 4.4 개발 방법론

애자일(Scrum) 방법론을 채택하며, 2주 단위 스프린트로 진행합니다. 1단계(Sprint 1-2)에서는 프로젝트 셋업, 기본 대시보드 레이아웃, 위젯 프레임워크 구축 및 업비트 API 연동을 통한 암호화폐 시세 표시를 구현합니다. 2단계(Sprint 3-4)에서는 국내 주식 시세/차트, 종목 정보 표시, 종목 교체 기능을 개발합니다. 3단계(Sprint 5-6)에서는 금/은 시세, 국내외 시장지수, 뉴스 피드 위젯을 추가합니다. 4단계(Sprint 7-8)에서는 실시간 WebSocket 연동 고도화, 성능 최적화, UI/UX 개선 및 통합 테스트를 수행합니다. 각 스프린트 종료 시 동작하는 산출물을 데모하여 피드백을 반영하며, Git 기반 버전 관리와 CI/CD 파이프라인(GitHub Actions)을 통해 지속적 통합·배포 환경을 유지합니다. 프론트엔드와 백엔드 작업은 병렬로 진행하되, API 인터페이스 명세(OpenAPI/Swagger)를 사전에 합의하여 독립적 개발이 가능하도록 합니다.
