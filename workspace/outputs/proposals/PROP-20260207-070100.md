## 1. 경영진 요약 (Executive Summary)

> **귀사의 스마트팩토리 도약을 위한 핵심 솔루션을 제안드립니다.**

### 한눈에 보는 프로젝트

| 항목 | 내용 |
|------|------|
| **해결할 문제** | MES-APS 간 15분 배치 연동으로 인한 실시간 의사결정 불가 및 연간 8억원 유지보수 비용 |
| **우리의 솔루션** | 클라우드 하이브리드 기반 통합 MES/APS 플랫폼 신규 구축 |
| **예상 기간** | 18개월 (2026.07 ~ 2027.12) |
| **투입 공수** | 180 Man-Months (40명 투입) |
| **핵심 기대효과** | **OEE 5%p 개선** (78% → 83%), 납기 준수율 97% 달성 |

> **왜 지금 해야 하는가?**
>
> 현재 레거시 시스템(MES 2012년, APS 2015년)의 노후화로 화면 응답시간 5.2초, 연간 유지보수비 8억원이 발생하고 있습니다. 글로벌 Top Tier 철강사 대비 OEE 10%p 격차가 벌어지고 있으며, 이대로 두면 경쟁력 격차는 더욱 확대될 것입니다. 지금이 디지털 전환을 통해 스마트팩토리로 도약할 최적의 시점입니다.

## 2. 현재 상황: 왜 변화가 필요한가?

> **귀사 현장의 목소리에 귀 기울였습니다.**

### 2.1 현재의 도전과 고통

| 문제 영역 | 현상 | 비즈니스 영향 |
|----------|------|--------------|
| **시스템 분절** | MES-APS 15분 배치 연동, 수작업 엑셀 재정리 | 계획 수립 4시간 소요, 긴급 수주 대응 지연 |
| **노후화된 UI** | 화면 전환 5~10초, 실적 입력 누락 | 현장 조업자 업무 효율 저하, 데이터 정확도 하락 |
| **단절된 데이터** | 품질-공정-설비 데이터 분리 | 클레임 원인 분석 16시간, 불량 확산 방지 지연 |
| **비현실적 스케줄** | APS가 두께 점프, 이송 시간 미반영 | 스케줄 준수율 저조, 주 2~3회 재계획 |
| **납기 관리 어려움** | 납기 위험 코일 사전 감지 불가 | 납기 준수율 92%, 고객 불만 1위 |

### 2.2 변화하지 않으면?

> **현재 방식을 유지할 경우:**
> - **경쟁력 악화**: 글로벌 Top Tier 대비 OEE 격차 지속 확대
> - **비용 증가**: 레거시 유지보수 비용 연 10% 이상 증가 예상 (8억 → 10억+)
> - **고객 이탈 위험**: 자동차강 JIT 납품 실패 시 주요 고객 이탈
> - **인재 유출**: 구시대적 시스템으로 인한 현장 인력 사기 저하

### 2.3 변화했을 때의 미래

> **프로젝트 성공 후 귀사의 모습:**
>
> - **조업반장 박성호**: "이제 코일 위치를 실시간으로 확인해요. 야드맨한테 무전할 필요 없어요. 압연 속도, 장력, 두께를 한 화면에서 트렌드로 보니 공정 이상을 바로 잡을 수 있어요."
>
> - **생산관리팀 정은지 팀장**: "계획 수립이 4시간에서 30분으로 줄었어요. 긴급 수주가 들어와도 What-if 시뮬레이션으로 영향도를 즉시 확인하고 대응합니다."
>
> - **품질관리팀 한승우 과장**: "클레임이 발생하면 30분 안에 전 공정 데이터를 추출해요. 예전엔 16시간 걸렸는데, 이제는 원인을 바로 찾아 재발을 방지합니다."

## 4. 우리의 솔루션

> **현장의 고통을 해결하는 통합 플랫폼**

### 4.1 솔루션 개요

**NEXUS (Next-generation EXecution & Unified Scheduling)** - 냉연 전 공정 9개 라인을 통합하는 차세대 MES/APS 플랫폼

- **실시간 통합**: MES-APS 간 2초 이내 실시간 데이터 연동
- **지능형 스케줄링**: 냉연 특화 15개 제약조건을 반영한 최적 스케줄링
- **디지털 트윈**: 공장 전체 현황을 한눈에 파악하는 통합 대시보드
- **모바일 대응**: PWA 기반 언제 어디서나 KPI 조회 및 알림

### 4.2 작업 범위

#### 포함 범위 (In-Scope)

| 구분 | 내용 | 고객 가치 |
|------|------|----------|
| **APS 스케줄링** | 통합 생산계획, 제약조건 스케줄링, What-if 시뮬레이션 | 계획 수립 87% 단축, 스케줄 준수율 향상 |
| **MES 핵심** | 작업지시, 코일 추적, 실시간 데이터 수집, 재공 관리 | 실시간 현황 파악, 코일 위치 99% 정확도 |
| **품질 관리** | SPC, 품질 판정, 성적서 자동화, 클레임 역추적 | 불량률 감소, 분석 시간 97% 단축 |
| **설비 관리** | OEE 자동 산출, 롤 교체 알림, 정비 일정 연동 | 설비 가동률 향상 |
| **분석/리포팅** | 통합 대시보드, KPI 관리, 생산일보 자동화 | 의사결정 속도 향상 |
| **시스템 연동** | SAP, Level 2, LIMS, WMS, EMS, BI 연동 | 데이터 사일로 해소 |
| **현장 UI** | 터치스크린 전용 UI, 다크 모드, PWA | 현장 사용성 극대화 |

#### 제외 범위 (Out of Scope)

> - **품질 예측 AI/ML 모델** - 2차 사업 범위로 분리 (데이터 축적 후 진행)
> - **열연/후판 공장 확대** - 냉연 성공 후 확장 검토
> - **네이티브 모바일 앱** - PWA로 대체하여 개발/유지보수 비용 절감
