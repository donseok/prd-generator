# 시스템 모니터링 웹 대시보드 요구사항

## 프로젝트 개요
실시간 시스템 리소스 모니터링을 위한 웹 기반 대시보드 개발

## 모니터링 항목

### 1. CPU 사용량
- 실시간 라인 차트로 CPU 사용률(%) 표시
- 시간축 기반 트렌드 시각화

### 2. 메모리 사용량
- 실시간 라인 차트로 메모리 사용률(%) 표시
- 전체 메모리 대비 사용량 표시

### 3. 디스크 사용량
- 파이 차트로 디스크 사용/잔여 공간 시각화
- 각 드라이브별 사용량 표시

### 4. 네트워크 트래픽
- IN/OUT 트래픽을 실시간 차트로 표시
- 수신(Bytes In) / 송신(Bytes Out) 구분 시각화

## 기술 스택

### Frontend
- React
- Recharts (차트 라이브러리)

### Backend
- Python
- psutil (시스템 정보 수집 라이브러리)

## 기능 요구사항

### 실시간 업데이트
- 3초 간격으로 시스템 정보 자동 갱신
- 백엔드 API를 통한 데이터 수집 및 전달

### UI/UX
- 다크 테마 적용
- 깔끔하고 직관적인 레이아웃
- 반응형 대시보드 그리드 구성
