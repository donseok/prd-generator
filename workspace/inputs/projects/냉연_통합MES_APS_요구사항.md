# 냉연 통합 MES/APS 시스템 구축 프로젝트 - 사용자 요구사항서

## 1. 프로젝트 개요

### 1.1 프로젝트 배경
- 현재 냉연공장의 MES(Manufacturing Execution System)와 APS(Advanced Planning & Scheduling)가 별도 시스템으로 운영 중
- MES-APS 간 데이터 연동 지연(평균 15분)으로 실시간 의사결정 불가
- 레거시 MES 시스템(2012년 구축) 노후화로 유지보수 비용 증가(연간 8억원)
- 글로벌 철강사 대비 생산성 격차 해소 필요(OEE 기준 12% 차이)

### 1.2 프로젝트 목표
- MES와 APS를 하나의 통합 플랫폼으로 구축
- 실시간 생산 모니터링 및 스케줄링 최적화
- 냉연 공정 특화 기능 강화(코일 추적, 품질 예측, 설비 연동)
- PI(Process Innovation) 기반 업무 프로세스 혁신

### 1.3 대상 공정
- PCM(Pickling & Cold Rolling Mill): 산세-냉간압연 연속라인
- BAF(Batch Annealing Furnace): 상자소둔로
- CAL(Continuous Annealing Line): 연속소둔라인
- EGL(Electro Galvanizing Line): 전기아연도금라인
- CGL(Continuous Galvanizing Line): 용융아연도금라인
- SPM(Skin Pass Mill): 조질압연기
- RCL(Recoiling Line): 정정라인
- SL(Slitting Line): 슬리팅라인
- CCL(Color Coating Line): 컬러도장라인

## 2. 기능 요구사항 (Functional Requirements)

### 2.1 생산계획 관리 (APS 핵심)

#### FR-001: 통합 생산계획 수립
- 월간/주간/일간 생산계획을 단일 화면에서 수립
- 수주 정보(ERP 연동)를 기반으로 자동 계획 초안 생성
- 코일 단위 세부 스케줄링 지원
- 납기일 역산 방식의 자동 일정 산출

#### FR-002: 제약조건 기반 스케줄링
- 설비 능력(Capacity) 제약: 라인별 처리 가능 두께/폭/강종 범위
- 연속작업 제약: 두께 점프(Thickness Jump) 최소화 규칙
- 롤 교체 주기 제약: 압연 롤 마모도 기반 교체 시점 반영
- 소둔로 장입 패턴 최적화: BAF 코일 적재 순서/조합 최적화
- 도금량 변경 최소화: EGL/CGL 도금량 전환 횟수 최소화
- 에너지 비용 최적화: 전력 피크 시간대 회피 스케줄링

#### FR-003: 실시간 스케줄 조정
- Gantt Chart 기반 드래그&드롭 일정 변경
- What-if 시뮬레이션: 설비 고장, 긴급 수주 시 영향도 분석
- 자동 재스케줄링: 실적 대비 계획 차이 발생 시 자동 보정
- 계획 확정/미확정 구분 관리

#### FR-004: 수주-생산 연계
- ERP 수주 데이터 실시간 연동 (SAP RFC/BAPI)
- 수주 우선순위 자동 반영 (납기, 고객 등급, 수익성)
- 가용 재고(모코일) 자동 할당
- 잔여 능력(Available Capacity) 실시간 조회

### 2.2 생산실행 관리 (MES 핵심)

#### FR-005: 작업지시 관리
- APS 확정 계획 기반 작업지시 자동 생성
- 라인별 작업지시 큐(Queue) 관리
- 작업지시 상태 관리: 대기 → 준비 → 진행 → 완료 → 마감
- 긴급 작업지시 삽입 및 우선순위 변경

#### FR-006: 코일 추적 관리 (Coil Tracking)
- 코일 ID 기반 전 공정 이력 추적
- 실시간 코일 위치 추적 (라인 내/야드/창고)
- 코일 분할(Slitting)/합병 이력 관리
- 모코일-자코일 계보(Genealogy) 관리
- 바코드/QR 스캔 기반 코일 입출고

#### FR-007: 실시간 조업 데이터 수집
- Level 2(PLC/HMI) 데이터 실시간 수집 (OPC-UA 프로토콜)
- 수집 주기: 압연 속도, 장력, 두께, 온도 등 핵심 태그 1초 단위
- 데이터 이상치 자동 감지 및 알람
- 히스토리안 서버 연동 (OSIsoft PI / Aveva)

#### FR-008: 품질 관리
- 공정별 품질 검사 항목 관리 (두께, 폭, 표면결함, 기계적성질)
- SPC(Statistical Process Control) 관리도 실시간 표시
- 품질 판정 자동화: 규격 대비 자동 합부 판정
- 품질 이상 발생 시 해당 코일 자동 격리(Hold) 처리
- 고객 클레임 이력과 공정 데이터 연계 분석

#### FR-009: 설비 관리 연동
- 설비 상태 모니터링 (가동/정지/고장/정비)
- 설비 고장 시 MES-APS 연동 자동 재스케줄링 트리거
- 정기 정비 일정 APS 반영
- 설비 OEE(Overall Equipment Effectiveness) 자동 산출
- 롤/다이 교체 이력 관리

#### FR-010: 재공품(WIP) 관리
- 공정 간 재공 재고 실시간 현황
- 야드(Yard) 관리: 코일 적치 위치, 적치 시간
- 재공 체류 시간 모니터링 및 초과 알람
- 공정 간 이송 지시 및 추적

### 2.3 통합 기능

#### FR-011: 통합 대시보드
- 공장 전체 생산 현황 한눈에 조회 (Digital Twin 개념)
- 라인별 가동률, 생산량, 품질 지표 실시간 표시
- 계획 대비 실적 비교 차트
- 이상 상황 종합 알람 센터

#### FR-012: KPI 관리
- 일/주/월 단위 KPI 자동 산출 및 리포트
- 주요 KPI: OEE, 납기준수율, 수율, 품질불량률, 재공회전율
- KPI 목표 대비 실적 트렌드 분석
- 부서별/라인별 성과 비교

#### FR-013: 데이터 분석 및 리포트
- 생산일보/월보 자동 생성
- Ad-hoc 분석용 데이터 조회 (Pivot 기능)
- Excel/PDF 리포트 다운로드
- BI 도구(Tableau/Power BI) 연동용 데이터 마트

#### FR-014: 시스템 연동
- ERP(SAP): 수주, 출하, 자재, 원가 데이터 양방향 연동
- Level 2(공정 컴퓨터): 설정값 전송, 실적 수신 (OPC-UA)
- LIMS(품질분석시스템): 시험 결과 연동
- WMS(창고관리시스템): 제품 입출고 연동
- 에너지관리시스템(EMS): 에너지 사용량 연동

## 3. 비기능 요구사항 (Non-Functional Requirements)

### 3.1 성능
- NFR-001: 화면 응답시간 3초 이내 (95th percentile)
- NFR-002: 실시간 데이터 수집 지연 2초 이내
- NFR-003: APS 스케줄링 연산 시간: 1주일 계획 기준 5분 이내
- NFR-004: 동시 사용자 300명 이상 지원
- NFR-005: 일일 트랜잭션 처리량 500만 건 이상

### 3.2 가용성
- NFR-006: 시스템 가용률 99.9% (연간 다운타임 8.76시간 이내)
- NFR-007: 장애 발생 시 복구시간(RTO) 30분 이내
- NFR-008: 데이터 손실 허용범위(RPO) 1분 이내
- NFR-009: 무중단 배포(Zero Downtime Deployment) 지원

### 3.3 보안
- NFR-010: 역할 기반 접근제어(RBAC) 적용
- NFR-011: 공장 네트워크 DMZ 구성 (OT/IT 네트워크 분리)
- NFR-012: 데이터 암호화: 전송 시 TLS 1.3, 저장 시 AES-256
- NFR-013: 감사 로그(Audit Trail) 전수 기록

### 3.4 확장성
- NFR-014: 향후 열연/후판 공장 확대 적용 가능한 아키텍처
- NFR-015: 마이크로서비스 기반 모듈 독립 배포
- NFR-016: 클라우드 하이브리드 배포 지원 (On-premise + Cloud)

### 3.5 사용성
- NFR-017: 웹 기반 UI (반응형, 태블릿 지원)
- NFR-018: 다국어 지원 (한국어, 영어, 일본어)
- NFR-019: 현장 터치스크린 전용 UI 제공
- NFR-020: 사용자 교육 없이 기본 조회 가능한 직관적 UX

## 4. 제약 조건 (Constraints)

### 4.1 기술 제약
- CONST-001: 기존 SAP ERP (S/4HANA) 환경과 호환 필수
- CONST-002: 기존 Level 2 시스템(ABB/Siemens PLC) 유지, OPC-UA 통신
- CONST-003: 기존 히스토리안(OSIsoft PI) 데이터 마이그레이션 필수
- CONST-004: 사내 보안 정책 준수 (망분리, USB 차단 등)

### 4.2 일정 제약
- CONST-005: 2026년 하반기(7월) 착수, 2027년 12월 1차 Go-Live 목표
- CONST-006: 정기 수리 기간(4월, 10월) 활용 현장 테스트
- CONST-007: 기존 MES 병행 운영 기간 최소 3개월

### 4.3 조직 제약
- CONST-008: 현장 운영 인력의 변화 저항 최소화 (기존 업무 흐름 유지)
- CONST-009: 프로젝트 전담 인력 투입: 사내 15명, 외부 25명

## 5. 인터페이스 요구사항

### 5.1 사용자 인터페이스
- UI-001: 웹 브라우저 기반 (Chrome, Edge 최신 2개 버전 지원)
- UI-002: 대형 모니터(55인치) 현황판 전용 뷰
- UI-003: 모바일 웹 알림 수신 (관리자용)

### 5.2 시스템 인터페이스
- IF-001: SAP ERP ↔ MES: RFC/BAPI, 실시간 + 배치(일 2회)
- IF-002: Level 2 ↔ MES: OPC-UA, 실시간(1초 주기)
- IF-003: MES ↔ LIMS: REST API, 이벤트 기반
- IF-004: MES ↔ WMS: REST API, 실시간
- IF-005: MES → BI: 데이터 마트(ETL, 일 1회)

## 6. 데이터 요구사항

### 6.1 마스터 데이터
- 설비 마스터: 라인, 설비, 센서 정보
- 제품 마스터: 강종, 규격, 품질 기준
- 공정 마스터: 공정 경로, 표준 작업 조건
- 고객/수주 마스터: ERP 연동

### 6.2 트랜잭션 데이터
- 작업지시, 공정실적, 품질검사, 설비이벤트
- 일일 예상 데이터량: 약 2TB (Level 2 태그 데이터 포함)

### 6.3 데이터 보관
- 운영 데이터: 3년 온라인 보관
- 이력 데이터: 10년 아카이브 보관
- Level 2 태그 데이터: 1년 상세, 5년 요약

## 8. 기대 효과

- 생산성 향상: OEE 5%p 개선 (현재 78% → 목표 83%)
- 납기 준수율: 92% → 97%
- 품질 불량률: 1.2% → 0.7%
- 재공 재고 감소: 15% 절감
- 에너지 비용: 8% 절감
- 계획 수립 시간: 4시간 → 30분
