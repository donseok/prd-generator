# 변화관리 및 교육 요구사항

## 작성 배경
PI 킥오프 회의(2026-06-02)에서 이동건 상무 지시:
> "시스템이 아무리 좋아도 현장에서 안 쓰면 소용없습니다. 변화관리에 충분한 리소스를 배정하세요."

현장 인터뷰 결과, 기존 MES 도입 시(2012년) 변화관리 미흡으로 6개월간 수작업 병행한 사례가 있어 이번에는 체계적 접근 필요.

---

## 1. 사용자 그룹별 요구사항

### 1.1 현장 조업자 (약 200명)
**특성**: 교대 근무(4조 3교대), PC 활용도 중간, 변화에 보수적
**핵심 요구**:
- 기존 업무 흐름 최대한 유지하면서 점진적 전환
- 터치스크린 기반 직관적 UI (장갑 착용 상태에서 조작 가능)
- 화면 전환 최소화 (핵심 정보를 한 화면에)
- 한글 인터페이스 (영어 메뉴 금지)
- 실수 방지 기능 (확인 팝업, 되돌리기)
- 야간 근무 시 눈 피로 감소 (다크 모드)

**교육 요구**:
- 교대 근무 고려한 반복 교육 (4조 × 3회 = 12회 이상)
- 실 작업 환경에서의 hands-on 교육
- 동영상 매뉴얼 (5분 이내 단위별)
- 현장 슈퍼유저 양성 (라인당 2명)

### 1.2 생산관리자 (약 30명)
**특성**: 일근, PC 활용도 높음, 엑셀 숙련
**핵심 요구**:
- 엑셀 다운로드/업로드 기능 (기존 업무와 호환)
- 계획 수립 시 기존 엑셀 기반 → 시스템 기반 전환
- 개인화 가능한 대시보드
- 다중 모니터 지원

**교육 요구**:
- APS 시뮬레이션 기능 집중 교육 (2일 과정)
- 계획 수립 워크숍 (실 데이터 기반)
- 시스템 관리자 과정 (파라미터 설정, 마스터 관리)

### 1.3 품질/설비 관리자 (약 20명)
**핵심 요구**:
- SPC 관리도 커스터마이징
- 분석용 데이터 추출 기능 (Pivot, 필터링)
- 리포트 템플릿 자유 편집

### 1.4 경영진/팀장급 (약 15명)
**핵심 요구**:
- 모바일 웹에서 핵심 KPI 조회
- 이메일/SMS 알림 (이상 상황)
- 1-page 리포트 (일일/주간 요약)

## 2. UI/UX 요구사항

### 2.1 공통
- 웹 기반 (Chrome, Edge 최신 2개 버전)
- 반응형 디자인 (PC, 태블릿, 대형 모니터)
- 다크 모드 / 라이트 모드 전환
- 다국어 (한국어 기본, 영어, 일본어)
- 접근성: WCAG 2.1 AA 수준

### 2.2 현장 전용
- 55인치 대형 모니터 현황판 레이아웃
- 터치스크린 전용 UI (버튼 크기 최소 48px)
- 음성 알람 지원
- 색맹/색약 대응 (색상 + 아이콘 + 패턴 병행)

### 2.3 사무실 전용
- 듀얼 모니터 최적화 레이아웃
- 키보드 단축키 지원
- 드래그&드롭 Gantt Chart
- 데이터 그리드 정렬/필터/그룹핑

## 4. 병행 운영 계획

- 기존 MES와 신규 시스템 최소 3개월 병행 운영
- 병행 기간 중 데이터 정합성 비교 (일일 체크)
- 전환 기준: 신규 시스템 데이터 일치율 99.5% 이상, 3일 연속 달성 시 전환
- 롤백 계획: 전환 후 2주간 기존 시스템 대기 모드 유지
