2. 핵심 문제점
------------------

[문제 1] MES-APS 데이터 연동 지연
- 현상: 배치 연동 주기 15분, 피크 시 최대 30분 지연
- 영향: 설비 고장/긴급 수주 반영 지연으로 계획 신뢰도 저하
- 정량 지표: 계획 대비 실적 일치율 68% (목표 90% 이상)
- 근본원인: EAI 미들웨어 병목, 두 시스템 간 데이터 모델 불일치

[문제 2] MES 성능 저하
- 현상: 화면 응답 시간 평균 5.2초 (피크 시 12초)
- 영향: 현장 실적 입력 지연, 수작업 보정 작업 증가
- 정량 지표: 월평균 수작업 보정 건수 340건
- 근본원인: DB 인덱스 최적화 미흡, 서버 노후화 (CPU 사용률 평균 78%)

[문제 3] APS 스케줄링 정확도 부족
- 현상: 냉연 공정 특수 제약조건 미반영
- 미반영 제약 목록:
  * 두께 점프 규칙 (연속 코일 간 두께 차이 제한)
  * 강종 전환 규칙 (도금량 변경, 소둔 온도 변경)
  * 코일 이송 시간 (공정 간 물류 시간)
  * 롤 교체/정비 시간 (강종별 차등)
  * 에너지 피크/비피크 구분
- 영향: 수작업 재계획 빈도 주 2~3회, 계획 수립 시간 4시간/회
- 정량 지표: 스케줄 준수율 72%

[문제 4] 코일 추적 불완전
- 현상: 공정 간 코일 위치 확인에 수작업(무전/전화) 의존
- 영향: 코일 탐색 시간 평균 25분, 분실 코일 월 평균 3건
- 정량 지표: 코일 위치 정확도 85% (야드 기준)
- 근본원인: 바코드 스캔 누락, 이송 실적 미입력

[문제 5] 품질 데이터 단절
- 현상: MES 품질 데이터, Level 2 공정 데이터, LIMS 시험 데이터가 분리
- 영향: 품질 원인 분석에 평균 2일 소요, 클레임 대응 지연
- 정량 지표: 품질 불량률 1.2%, 클레임 건당 분석 시간 16시간
- 근본원인: 시스템 간 코일 ID 체계 불일치, 통합 조회 불가

[문제 6] 리포팅 비효율
- 현상: 생산일보 작성에 수작업 2시간/일, 데이터 취합이 대부분
- 영향: 관리자 업무 시간의 25%가 리포트 작성
- 정량 지표: 월간 리포트 작성 공수 120 man-hour
- 근본원인: 데이터가 여러 시스템에 분산, 통합 리포팅 도구 부재
