## 1분 만에 시작하기

### Step 1. 입력 파일 준비

프로젝트 요구사항이 담긴 파일을 아래 폴더에 넣습니다:

```
workspace/inputs/projects/
```

지원 형식: TXT, MD, EML, XLSX, CSV, PPTX, PDF, DOCX, PNG, JPG, JSON

### Step 2. 문서 생성

#### 방법 A: 전체 문서 일괄 생성 (추천)

```bash
python -m app.scripts.auto_doc
```

PRD → TRD → WBS → 제안서 → PPT 순서로 모든 문서를 자동 생성합니다.

#### 방법 B: 웹 대시보드 사용

1. 브라우저에서 `http://localhost:3000` 접속
2. 생성된 문서를 확인하고 JSON/MD 형식으로 열람

### Step 3. 결과 확인

생성된 파일은 `workspace/outputs/` 아래 폴더별로 저장됩니다.

## 주요 CLI 명령어 모음

### 문서 생성

| 명령어 | 설명 |
|--------|------|
| `python -m app.scripts.auto_doc` | 전체 5종 문서 일괄 생성 |
| `python -m app.scripts.prd_maker` | PRD만 생성 |
| `python -m app.scripts.trd_maker` | TRD만 생성 |
| `python -m app.scripts.wbs_maker` | WBS만 생성 |
| `python -m app.scripts.pro_maker` | 제안서만 생성 |
| `python -m app.scripts.pro_maker --client "고객사명"` | 고객사명 지정하여 제안서 생성 |
| `python -m app.scripts.ppt_maker` | PPT만 생성 (~23장) |
| `python -m app.scripts.arch_diagram` | 아키텍처 다이어그램 생성 |

### 문서 변환 (DOCX)

| 명령어 | 설명 |
|--------|------|
| `python -m app.scripts.doc_maker` | 전체 DOCX 변환 |
| `python -m app.scripts.doc_maker --type prd` | PRD만 DOCX 변환 |
| `python -m app.scripts.doc_maker --type trd` | TRD만 DOCX 변환 |
| `python -m app.scripts.doc_maker --type wbs` | WBS만 DOCX 변환 |
| `python -m app.scripts.doc_maker --type proposal` | 제안서만 DOCX 변환 |

---

## 생성 순서 (의존 관계)

```
① PRD  →  ② TRD  →  ③ WBS  →  ④ 제안서  →  ⑤ PPT
              ↓                                  ↓
       아키텍처 다이어그램                       DOCX
```

각 단계는 이전 단계의 출력이 필요합니다. `auto_doc`을 사용하면 자동 처리됩니다.

---

## 출력 파일 위치

```
workspace/outputs/
├── prd/        → PRD (MD, JSON)
├── trd/        → TRD (MD, JSON)
├── wbs/        → WBS (MD, JSON)
├── proposals/  → 제안서 (MD, JSON)
├── ppt/        → 프레젠테이션 (PPTX)
├── doc/        → Word 문서 (DOCX)
└── diagrams/   → 아키텍처 다이어그램 (PNG)
```

## 웹 대시보드 핵심 기능

| 기능 | 설명 |
|------|------|
| **문서 목록** | 생성된 모든 문서를 유형별로 필터링하여 조회 |
| **JSON 보기** | 문서의 구조화된 데이터를 트리 형태로 조회 |
| **MD 보기** | 마크다운 렌더링된 문서 내용 조회 |
| **PPTX 열기** | PowerPoint 프로그램으로 직접 열기 |
| **테마 전환** | 라이트/다크 모드 전환 |
| **일괄 삭제** | 모든 생성 문서 삭제 |

## 자주 쓰는 시나리오

### 시나리오 1: 처음부터 전체 문서 생성

```bash
# 1. 입력 파일을 workspace/inputs/projects/에 넣기
# 2. 전체 생성
python -m app.scripts.auto_doc
```

### 시나리오 2: 제안서만 다시 만들기

```bash
python -m app.scripts.pro_maker --client "ABC 주식회사"
```

### 시나리오 3: Word 문서로 변환

```bash
python -m app.scripts.doc_maker
```

### 시나리오 4: 깨끗하게 초기화 후 재시작

```bash
# Claude Code 환경에서
/del:del-all

# 새 입력 파일 넣고
python -m app.scripts.auto_doc
```

## 문제가 발생하면?

| 증상 | 해결 방법 |
|------|-----------|
| "입력 파일이 없습니다" | `workspace/inputs/projects/`에 파일이 있는지 확인 |
| "PRD가 없습니다" | PRD를 먼저 생성: `python -m app.scripts.prd_maker` |
| 대시보드 접속 불가 | 서버 실행 확인: `/web:dash-board` 또는 수동 실행 |
| 문서 내용이 부실 | 입력 파일에 더 상세한 요구사항 작성 |
